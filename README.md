「특허-산업 융합데이터 활용 아이디어 공모전」(지식재산처·KISTA, 2026) 출품작
**“특허 한 건마다 붙은 산업 라벨로 읽는 산업 생애주기 조기경보”**의 분석 코드 저장소다.

## 이 저장소에 있는 것 / 없는 것

- **있음:** `분석/` 폴더의 코드(`.py`, `.js`, `.ps1`)만.
- **없음(의도적으로 제외):** 공모전 제공 데이터와 그 파생 데이터, 수집 DB, 결과표(csv·json·parquet), 그림, 보고서 원고, API 키.
  - 공모전 서약서 6항: 제공 데이터는 팀원 외 공유 금지, 공모전 종료 후 폐기.
  - 따라서 이 코드는 **로컬 데이터가 있는 팀 PC에서만** 실행된다. 클론만으로는 재현되지 않는다.
- 커밋 가드: `.githooks/guard.py`(pre-commit). 데이터 확장자, 5MB 초과 파일, 키 문자열을 막는다.
  처음 클론하면 `git config core.hooksPath .githooks` 로 켠다.

## 공통 규칙(코드에 반영됨)

- **전진 검증:** 원점까지 알 수 있던 정보로만 학습한다. 최종시험 구간은 잠가 두고 동결 후 1회만 채점한다.
- **지표:** skill = (AUC_모형 − AUC_기준선) / (1 − AUC_기준선). AUC와 상위 k 적중률을 함께 보고한다.
- **필수성 시험:** 제공 KSIC 라벨을 공개 자료 배정(연계표·해설서 텍스트·IPC 최빈표)으로 바꿔 같은 과제를 다시 잰다.
- 경로는 팀 PC의 로컬 경로를 가정한다(`C:\Users\PC\Downloads\특허-산업 융합데이터 활용 아이디어 공모전\...`).

## 클라우드 세션에서 이어서 작업할 때

- 이 저장소에는 데이터가 없다. 클라우드에서는 **코드 정리·리팩터링·주석·README·제출용 코드 패키지 구성**만 할 수 있다.
- 모형 재학습·재채점처럼 데이터가 필요한 일은 팀 PC에서 한다.
- 데이터 파일, 결과표, API 키는 어떤 경우에도 커밋하지 않는다.
